## Build inputs and result

`tools/build.sh --steam-frame` was attempted from the same clean checkout without a game package. CMake configured, then Ninja stopped because `native/src/AircraftHlodData.S` includes `aircraft-hlod-global/aircraft.hlod`, which is generated by `tools/assemble.py` from the game package's data APK. No replacement or placeholder data was supplied.

A local candidate reports the requested version and ARM64 ABI, but its signer does not match the pinned Google Play source signer. It was not used and the signer guard was not bypassed. A full native/package build therefore remains unverified until the matching user-owned source package is available. The prior device observations in [STEAM_FRAME.md](STEAM_FRAME.md) are separate from this clean-build result.

Personal combined packages include proprietary game files and are not distributable as source-kit artifacts. This readiness record does not claim a distributable APK or a device-tested build.
